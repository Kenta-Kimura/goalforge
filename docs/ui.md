# UI

## UI原則

- 教材の構造編集は「教材管理」、学習の記録は「演習」に分離します。
- ダッシュボードは統計表示を担当し、マスターデータを直接編集しません。
- サンプル・手入力・同期済みデータを区別して表示します。
- SQLiteが必要な操作はTauri版に限定し、ブラウザ表示では理由を案内します。
- Safariを主なWeb表示確認対象とし、TauriのWebViewでも安定するAPIを選びます。

## 主要画面

| 画面 | 目的 | 主な操作・表示 |
|---|---|---|
| ダッシュボード | 学習状況の統計・分析 | 進捗、正答率、Anki状態、目標状況 |
| 教材管理 | 教材マスターの管理 | 教材、セクション、問題の追加・編集・削除 |
| 演習 | 学習履歴の記録 | 周回開始、解答、部分点、確信度、復習状態 |
| 解答履歴 | 問題ごとの履歴確認 | 履歴一覧、編集、削除、得点・満点・確信度 |
| 設定・データ管理 | 保存状態とデータ保護 | DB情報、SQLite完全バックアップ・復元、旧JSON Import、移行状態 |

## 画面間の責務

### 教材管理

教材・セクション・問題の構造だけを変更します。解答履歴や周回を教材編集フォームへ混在させません。

### 演習と解答履歴

教材マスターを参照して周回を開始します。解答ダイアログでは正誤または得点、確信度、メモ、次回の復習状態を入力します。履歴ダイアログは過去の解答を表示・編集します。

### ダッシュボード

保存された学習データを集計して表示します。集計元がサンプル、手入力、Anki同期のいずれかを利用者が判断できる表示を維持します。

### 設定・データ管理

現状は「データ管理」画面が設定相当の責務を担います。SQLiteの保存先、スキーマバージョン、バックアップ操作を集約します。一般設定が増えた場合に独立した「設定」画面へ分けるかはTODOです。
